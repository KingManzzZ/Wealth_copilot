## 一句话结论

**指标要"能算、能解释、能改"**：

- 储蓄率看流量，应急月数看存量，DTI 看还款压力，目标进度看执行，资产配置看匹配；
- 阈值可配置（尤其房贷 DTI 不能照搬美国 28/36）；
- 缺失维度剔除并重新归一化，不要用 0 填充；
- 总分必须有短板惩罚，否则"负债 5 分 + 其他 90 分"会被平均成 70 分。
