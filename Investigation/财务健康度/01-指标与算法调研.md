# 个人财务健康度：指标与算法调研

> **目的**：给 WealthPilot 的"财务健康度"卡片定一套**可计算、可解释、可测试**的指标与算法。
> **范围**：只研究"能从现有数据算出来的"指标；主观问卷、征信分等只做对照。
> **结论先行**：MVP 用 **5 维**（储蓄、应急、负债、目标、资产配置），
> 每维 0~100，加权总分 + 短板惩罚 + A/B/C/D 分级；缺失维度剔除并重新归一化。

---

## 1. 结论摘要

| 维度 | 权重 | 核心指标 | 数据来源 |
| :--- | ---: | :--- | :--- |
| 储蓄能力 | 25% | 储蓄率（近 3 个月均值） | `transactions` |
| 应急储备 | 20% | 现金类资产 / 月均支出（月数） | `assets` + `transactions` |
| 负债健康 | 25% | 月供收入比（DTI）+ 负债资产比 | `debts` + `transactions` + `assets` |
| 目标进度 | 15% | 实际进度 / 按时间应达进度 | `goals` |
| 资产配置 | 15% | 高风险资产占比 vs 风险承受能力 | `assets` + `basic_info` |

**总分** = 加权平均 − 短板惩罚；**分级**：A ≥ 85，B ≥ 70，C ≥ 55，D < 55。

## 2. 指标全景（按 6 类）

### A. 现金流与储蓄

| 指标 | 公式 | 健康区间 | 说明 |
| :--- | :--- | :--- | :--- |
| 储蓄率 | `(收入 − 支出) / 收入` | ≥ 20% 良好；≥ 30% 优秀 | 50/30/20 预算把 20% 作为储蓄目标；15% 是常见下限建议 |
| 结余率 | `结余 / 收入` | 同储蓄率 | 与储蓄率同源，**不要重复计分** |
| 正结余月份占比 | 近 12 个月结余 > 0 的月数 / 12 | ≥ 80% | 反映稳定性，可作"储蓄"维度的修正项 |
| 收入波动率 | 近 6 个月收入的 `标准差 / 均值` | ≤ 0.2 稳定 | 波动大时，应急月数要求应上调 |
| 必要支出占比 | 必要支出 / 总收入 | ≤ 50%~60% | 需要给交易分类打"必要/可选"标签 |

> 参考：50/30/20（50% 必要、30% 想要、20% 储蓄）见
> [Personal budget · Wikipedia](https://en.wikipedia.org/wiki/Personal_budget)。
> 储蓄的严格定义（收入 − 消费）见 [Saving · Wikipedia](https://en.wikipedia.org/wiki/Saving)。

### B. 流动性与应急

| 指标 | 公式 | 健康区间 | 说明 |
| :--- | :--- | :--- | :--- |
| 应急月数 | 现金类资产 / 月均支出 | **3~6 个月**；收入不稳取 6~12 | 最核心的韧性指标 |
| 流动比率 | 流动资产 / 月支出 | ≥ 3 | 与应急月数同源，二选一 |
| 现金占资产比 | 现金类资产 / 总资产 | 5%~20% | 太低流动性差，太高拖累收益 |
| 财务脆弱性 | 能否用现金覆盖 3 个月支出 / 400 元意外 | 是 / 否 | 参考美联储 SHED 的口径 |

> 参考：美联储 2025 年 SHED 报告显示，**55%** 的美国成年人有覆盖 3 个月支出的应急储蓄，
> **63%** 能用现金或其等价物覆盖 400 美元意外支出，**12%** 完全拿不出
> （[Federal Reserve, Savings and Investments](https://www.federalreserve.gov/publications/2026-economic-well-being-of-us-households-in-2025-savings-investments.htm)）。
> 这说明"3 个月"是一个有实证基础的韧性分界线，而不是拍脑袋的 6 个月。

### C. 负债

| 指标 | 公式 | 健康区间 | 说明 |
| :--- | :--- | :--- | :--- |
| 前端 DTI（房贷） | 月供 / 月收入 | ≤ 28% 稳健；≤ 36% 可接受 | 美国 28/36 规则的前半 |
| 后端 DTI | 全部月债务还款 / 月收入 | ≤ 36% 稳健；≤ 43% 警戒 | 43% 是美国合格房贷的常见上限 |
| 负债资产比 | 总负债 / 总资产 | ≤ 50%；≥ 70% 高风险 | 中国家庭房产占比高，需结合自住房 |
| 高息负债占比 | 信用卡/消费贷余额 / 总负债 | ≤ 10% | 高息负债优先偿还 |
| 偿债备付率 | 月可支配结余 / 月还款额 | ≥ 1.5 | 衡量"收入中断时还能撑多久" |

> 参考：28/36 规则、Fannie Mae 36%~45%、FHA 31/43、VA 41 等口径见
> [Debt-to-income ratio · Wikipedia](https://en.wikipedia.org/wiki/Debt-to-income_ratio)。
> **注意**：这些是美国房贷的审批口径，不能直接当作中国家庭的"健康线"。

### D. 资产与净值

| 指标 | 公式 | 健康区间 | 说明 |
| :--- | :--- | :--- | :--- |
| 净资产 | 总资产 − 总负债 | 越大越好 | 存量指标，不直接进评分（年龄差异大） |
| 净资产/年收入 | 净资产 / 年收入 | 随年龄上升 | 可做"同龄对比"，不适合做硬阈值 |
| 自住房占资产比 | 自住房价值 / 总资产 | 中国常见 50%~70% | 过高→流动性差；评分时自住房应打折 |
| 高风险资产占比 | 股票/偏股基金/加密等 / 可投资资产 | 与风险承受能力匹配 | 需给资产打"风险等级"标签 |

> 净资产是"结果"，不是"过程"。评分里更适合用它做**辅助解释**，而不是直接打分。

### E. 目标与退休

| 指标 | 公式 | 健康区间 | 说明 |
| :--- | :--- | :--- | :--- |
| 目标进度 | `current / target` | 越接近 100% 越好 | 单目标 |
| 进度偏差 | `实际进度 − 按时间应达进度` | ≥ 0 表示在轨 | 按 `deadline` 计算 |
| 目标储蓄缺口 | `(target − current) / 剩余月数` | ≤ 月结余 | 缺口大于结余→不可行 |
| 退休替代率 | 退休后年收入 / 退休前年收入 | 70%~80%（经验值） | 中国需考虑社保/养老金，不能照搬 |
| 退休缺口 | 所需退休资产 − 现有退休资产 | 越小越好 | 需要长期假设（收益率/通胀） |

> 退休替代率 70%~80% 是欧美理财规划里的常见经验值，**不是统一权威标准**；
> 中国有社保/企业年金，实际目标应做成可配置参数。

### F. 保障、行为与主观

| 指标 | 公式 | 健康区间 | 说明 |
| :--- | :--- | :--- | :--- |
| 保险保额/年收入 | 寿险保额 / 年收入 | 5~10 倍（"双十原则"） | 经验值，需按家庭责任调整 |
| 保费/年收入 | 年保费 / 年收入 | 5%~10% | 过高挤压现金流 |
| 预算执行率 | 实际支出 / 预算 | 80%~100% | 需要预算功能 |
| 主观财务健康 | CFPB 10 题量表 | 0~100 | 需要用户问卷，不适合自动计算 |
| FinHealth 四维 | Spend / Save / Borrow / Plan | 0~100 | 行业框架，适合做产品对照 |

> 参考：[CFPB Financial Well-Being Scale](https://www.consumerfinance.gov/data-research/research-reports/financial-well-being-scale/)、
> [FinHealth Score](https://finhealthnetwork.org/research/finhealth-score/)。
> 这两个是"问卷/综合框架"，本项目的自动评分不直接采用，但可作为维度命名的参照。

## 3. 核心指标的算法与阈值

### 3.1 储蓄率（权重 25%）

```text
近 3 个月：
  income_m  = 当月收入合计
  expense_m = 当月支出合计
  rate_m    = (income_m - expense_m) / income_m     # income_m > 0
saving_rate = mean(rate_m)                          # 缺失月份跳过
```

评分（线性 clamp，5% 以下 0 分，30% 以上 100 分）：

```text
score = 100 * clamp((saving_rate - 0.05) / (0.30 - 0.05), 0, 1)
```

边界：

- 某月收入为 0 → 跳过该月；三个月都无收入 → 维度缺失；
- 大额一次性收入/支出（年终奖、买房）会扭曲，**用中位数或剔除极端月**更稳；
- 储蓄率与"应急月数"有相关性，但一个看流量、一个看存量，可以同时保留。

### 3.2 应急月数（权重 20%）

```text
cash_like = 现金 + 活期 + 货币基金 + 短期存款   # 需要给资产打流动性标签
monthly_expense = 近 3 个月支出的中位数
months = cash_like / monthly_expense            # monthly_expense > 0
```

评分（0 个月 0 分，6 个月 100 分）：

```text
score = 100 * clamp(months / 6, 0, 1)
```

边界：

- **自住房、股票、长期理财不能算现金类**，否则会高估韧性；
- 收入波动大（自由职业）时，目标月数从 6 提到 9~12；
- 月支出为 0（新用户）→ 维度缺失，不要用 0 除。

### 3.3 负债健康（权重 25%）

用两个子指标合成：

```text
dti = 月债务还款合计 / 月收入
debt_ratio = 总负债 / 总资产

score_dti        = 100 * clamp((0.50 - dti) / (0.50 - 0.15), 0, 1)
score_debt_ratio = 100 * clamp((0.70 - debt_ratio) / (0.70 - 0.20), 0, 1)
score = 0.6 * score_dti + 0.4 * score_debt_ratio
```

解释：

- `dti = 15%` → 100 分；`dti = 50%` → 0 分；
- 负债率 20% → 100 分；70% → 0 分；
- 为什么 DTI 权重更高：**现金流压力比存量负债更能预测违约**；
- 中国房贷：月供/收入 50% 是银行常见审批上限，但"健康"建议控制在 30%~40%；
  阈值应做成可配置，不要写死美国 28/36。

### 3.4 目标进度（权重 15%）

```text
对每个目标：
  elapsed = (今天 - created_at) / (deadline - created_at)   # 0~1
  actual  = current / target                                  # 0~1
  gap     = actual - elapsed
  score_i = 100 * clamp(0.5 + gap * 2, 0, 1)                 # 在轨=50，超前50%=100，落后50%=0

按 target 金额加权平均；deadline 已过且未完成 → score_i = 20
```

边界：

- `target = 0` 或 `deadline` 缺失 → 跳过该目标；
- 目标很多时按金额加权，避免"小目标拉高平均"；
- 目标进度和储蓄率相关，但目标维度能捕捉"存了钱但没存对地方"。

### 3.5 资产配置（权重 15%，可选）

```text
risky_ratio = 高风险资产 / 可投资资产
tolerance   = basic_info.risk_tolerance   # 保守/稳健/积极
target      = {保守: 0.2, 稳健: 0.4, 积极: 0.6}
score = 100 * clamp(1 - abs(risky_ratio - target) / 0.5, 0, 1)
```

边界：

- 没有"资产风险等级"字段时，先按名称关键词粗分（股票/基金/币 vs 存款/货币）；
- 这是"匹配度"而不是"越高越好"，与风险测评结合；
- 数据不足时整维剔除。

## 4. 综合评分算法

### 4.1 归一化与加权

```python
def clamp(x, lo=0.0, hi=1.0):
    return max(lo, min(hi, x))

WEIGHTS = {
    "saving": 0.25,
    "emergency": 0.20,
    "debt": 0.25,
    "goal": 0.15,
    "allocation": 0.15,
}

available = {k: v for k, v in scores.items() if v is not None}
total_w = sum(WEIGHTS[k] for k in available)
weighted = sum(scores[k] * WEIGHTS[k] for k in available) / total_w
```

### 4.2 短板惩罚（防止"平均健康"）

```python
worst = min(available.values())
penalty = 10 * sum(1 for v in available.values() if v < 40)
overall = clamp(weighted - penalty, 0, 100)
# 或者更温和：overall = min(weighted, 0.6 * worst + 0.4 * weighted)
```

理由：负债 5 分、其他 90 分的人，加权平均仍有 70+，但实际很脆弱；
**财务健康是"最弱一环"问题**，不能让高分项掩盖致命短板。

### 4.3 分级

| 总分 | 等级 | 含义 |
| :--- | :--- | :--- |
| ≥ 85 | A | 稳健，抗风险能力强 |
| 70~84 | B | 基本健康，有 1~2 个短板 |
| 55~69 | C | 需要关注，存在明显风险 |
| < 55 | D | 高风险，优先补应急/降负债 |

### 4.4 数据不足

- 单维缺失 → 剔除并重新归一化权重；
- 可用维度 < 2 → `overall = 0`，`advice` 写"先补齐流水/资产/负债"，
  并加一个可选的 `data_quality: "insufficient"` 字段（前端可忽略）；
- 不要用 0 填充缺失维度，那会把"没数据"误判成"很差"。

## 5. 本项目落地映射

| 指标 | 现有数据 | 缺口 |
| :--- | :--- | :--- |
| 储蓄率 | `transactions`（按月聚合） | 无"必要/可选"分类；一次性收支需剔除 |
| 应急月数 | `assets.value` + 月支出 | **`assets` 没有"流动性/资产类型"字段**，只能用名称关键词粗分 |
| DTI | `debts.monthly_payment` + 月收入 | 收入以流水为准；无稳定收入时需提示 |
| 负债资产比 | `debts.remaining` + `assets` | 自住房是否计入、如何打折 |
| 目标进度 | `goals.current/target/deadline` | `created_at` 需有，才能算"按时间应达" |
| 资产配置 | `assets` + `basic_info.risk_tolerance` | 无"资产风险等级"字段 |
| 保险 | 无 | 需要新增保障表，或先不做这一维 |

### 建议的最小 schema 改动

```sql
-- 资产：区分现金类 / 投资 / 自住房 / 其他
ALTER TABLE assets ADD COLUMN asset_type TEXT DEFAULT 'other';
-- cash | investment | property | other

-- 债务：区分高息/低息（可选）
ALTER TABLE debts ADD COLUMN annual_rate REAL;

-- 目标：记录创建时间（若还没有）
-- goals.created_at 已存在则不用改
```

没有这些字段时，MVP 可以先用名称关键词 + 保守折扣（自住房按 70% 计入资产），
但要在返回里标注"估算口径"。

## 6. 中国语境校准

| 点 | 美国口径 | 中国调整 |
| :--- | :--- | :--- |
| 收入分母 | 税前/税后均有 | 用**可支配收入**（流水里的到手收入） |
| 房贷 | 28/36 规则 | 月供/收入 ≤ 30%~40% 更稳健；50% 是银行审批上限 |
| 自住房 | 计入净资产 | 计入资产但**不计入应急资金**；流动性差 |
| 社保/养老金 | 401k/IRA 为主 | 社保 + 企业年金 + 个人养老金，替代率不能照搬 70%~80% |
| 应急资金 | 3~6 个月 | 收入不稳定/自由职业取 6~12 个月 |
| 负债结构 | 信用卡/学贷 | 房贷为主，消费贷/信用卡利率高，优先偿还 |

## 7. 常见陷阱

1. **用单月数据**：年终奖、装修、看病会让某个月严重失真 → 用 3~6 个月中位数；
2. **分母为 0**：新用户无收入/无支出 → 维度缺失，不要 0 除，也不要用 0 填充；
3. **把自住房当现金**：应急月数会被严重高估；
4. **用税前收入算 DTI**：会低估压力；
5. **平均值掩盖短板**：必须加短板惩罚或取最弱项；
6. **指标重复计分**：储蓄率、结余率、正结余月份高度相关，只选一个进总分；
7. **照搬美国阈值**：28/36、43% DTI 是审批口径，不是中国家庭的健康线；
8. **阈值写死**：收入波动、年龄、家庭责任不同，阈值应可配置；
9. **只给分不给解释**：每个维度必须带 `advice`（为什么低、怎么改），否则用户不知道做什么；
10. **把健康度存库**：它是派生值，应由流水/资产/负债实时算，存库会制造第二份真相。
